## Remediation

- Refreshed vulnerable transitive packages to the lowest non-vulnerable versions
  accepted by their parent ranges with `bun audit fix`.
- Upgraded `markdownlint-cli` from `0.47.x` to `0.48.x` so its `minimatch` and
  `smol-toml` ranges accept patched releases.
- Added same-major overrides for `js-yaml@4.3.1`, `markdown-it@14.2.0`, and
  `undici@6.28.0`. Their parent packages otherwise pin vulnerable versions with
  exact or tilde ranges.
- Added a provider smoke regression test that loads `@google/genai` and verifies the
  patched `protobufjs` runtime floor without making a network request or using a
  credential.

## Compatibility Constraints

- `@google/genai` remains on major version 1 and `release-it` remains on major
  version 19, avoiding provider and release workflow API migrations.
- Overrides stay within each transitive package's existing major version.
- `markdownlint-cli@0.48.x` retains the same Node.js 20 minimum as `0.47.x`.
- The repository still declares Node.js 18 support, while existing direct packages
  such as `@google/genai` and `release-it` already require Node.js 20. This pre-existing
  engine mismatch is not broadened by this patch; Bun is the validated workflow.
