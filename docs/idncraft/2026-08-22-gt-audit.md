## Baseline

The issue reported `bun audit` exit code 1 with 78 advisories: 3 critical, 45 high, 27 moderate, and 3 low. The baseline included a production path through `@google/genai > protobufjs` and separate release, lint, and commit tooling paths.

## Classification and resolution

### Production/runtime paths

| Advisory path                                       | Classification | Resolution                                                                                                                          |
| --------------------------------------------------- | -------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `@google/genai > protobufjs` and `@protobufjs/utf8` | Runtime        | Upgrade `@google/genai` to `^1.52.0`; lock resolves `protobufjs@7.6.5` and its UTF-8 helper outside the reported vulnerable ranges. |
| `@google/genai > ws` and `openai > ws`              | Runtime        | Upgrade runtime SDK ranges; lock resolves `ws@8.21.3`, outside the reported vulnerable range.                                       |

No critical or high advisory remains on a production dependency path. No runtime risk acceptance is required.

### Dev-only paths

The remaining baseline paths were reachable only through development tooling: `release-it`, `@release-it/conventional-changelog`, `@commitlint/*`, ESLint, `markdownlint-cli`, `yaml-lint`, and `lint-staged`. Direct tooling updates are:

- `@release-it/conventional-changelog` `^11.0.0`
- `markdownlint-cli` `^0.49.1`
- `release-it` `^20.0.0`
- compatible patch/minor refreshes for the existing SDK, lint, formatting, and commit tooling ranges

These updates move the affected dev-only packages to patched resolutions, including `js-yaml`, `markdown-it`, `minimatch`, `smol-toml`, and `undici`.

## Compatibility constraint and exception

- Geeto's runtime engine contract remains Node `>=18.0.0`; runtime SDK updates stay within the existing `@google/genai` v1 and `openai` v6 majors.
- The upgraded release/lint toolchain publishes newer Node engine requirements than the runtime contract. The repository's Bun workflow remains the supported quality-check path; Node `22+` is required when invoking `markdownlint-cli@0.49.1` directly through Node.
- `release-it@20.2.1` pins `undici@7.28.0`. The root `overrides` entry intentionally selects `undici@7.29.0`, a same-major security patch, until a future `release-it` update carries that fix. This is the only dependency exception and is covered by the audit regression test.
